Personal Google OAuth integration

Google Assistant on Stream Deck

This page documents a private Google OAuth configuration used with the Google Assistant plugin for Elgato Stream Deck, developed independently by Danex360. The integration allows its owner to issue Google Assistant requests and smart-home commands from Stream Deck buttons.

Private, noncommercial use

What this OAuth configuration does

  • Connects the account owner's personal Google account to the locally installed Stream Deck plugin.
  • Allows the plugin to submit Google Assistant queries and commands, and return responses, within the permissions granted at Google's consent screen.
  • Uses Google's authorization flow for the owner's account. This website itself does not perform authentication or host a backend service.

Google account data and privacy

The integration uses the permissions requested by the third-party plugin, including Google Assistant access and identifying the signed-in account's email address. The developer states that OAuth tokens are stored locally in encrypted form and that the plugin communicates directly with Google services. For specific data handling, see the privacy policy.
